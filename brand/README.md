# sokomoko brand

## Essence

One marketplace across customer, admin, and partner workspaces.

## Name and wordmark

Write the name as lowercase `sokomoko`. The wordmark is drawn from geometric
paths, not typeset text. Each letter uses a 4px monoline stroke, square line
caps, miter joins, and only horizontal and vertical segments on the 4px grid.
The letters are 16 units high, so the stroke is one quarter of the letter
height. The `s` uses the mark's five-segment construction, sized to fit the
wordmark cell. JetBrains Mono remains the typeface for UI text only. Minimum
wordmark size: 18px on screen or 6mm in print. Leave clear space equal to half
the lowercase letter height on every side.

## Mark

The mark is an angular lowercase `s` made from one continuous right-angle
stroke. Its 4px stroke follows a 32×32 viewBox, with turns on the 8px grid.
Use the mark alone at 16px and above when space is limited or the name is
already clear. Use the wordmark alone in name-led contexts. Use the lockup when
both recognition and the name are needed; keep the mark to the left of the
wordmark. Reserve one quarter of the mark width as clear space around the mark.

## Colour

Use `#000` and `#fff`. Neutral greys are `#555`, `#8a8a8a`, `#f4f4f4`,
`#e8e8e8`, `#a6a6a6`, `#6e6e6e`, `#111`, and `#222`, matching the design
system's light and dark surfaces. Separators use the existing 12% and 28% ink
tokens in light mode and 16% and 34% ink tokens in dark mode. No hue is ever
used. Keep marks and wordmarks solid black or solid white; use grey only for
secondary information.

## Typography

JetBrains Mono is the typeface for UI text. Use the existing design scale:
12px, 13px, 15px, 18px, 22px, and 28px. Use tabular figures for prices,
quantities, and other aligned numbers. Font files ship at
`internal/ui/static/fonts/`.

## Layout and grid

Use the 4px base grid. Spacing steps are 4px, 8px, 12px, 16px, 24px, 32px,
and 48px. Align edges and gaps to these steps. Keep large areas empty. Do not
add decoration to fill space.

## Voice and writing

Use sentence case. Use verbs on buttons and nouns for headings. State rules
directly. Use numbers over words. Do not use exclamation marks, taglines, or
filler.

## Do / Don't

| Do | Don't |
| --- | --- |
| Use lowercase `sokomoko` and the approved mark geometry. | Capitalize, stretch, rotate, outline, or decorate the logo. |
| Use black, white, and the listed neutral greys. | Use hue, gradients, shadows, textures, or 3D effects. |
| Build hierarchy with scale, weight, and space. | Add ornaments, slogans, or stock marketplace symbols. |
| Keep layouts sparse and align them to the 4px grid. | Fill negative space with filler copy or decoration. |
| Use JetBrains Mono and tabular figures. | Add another typeface or use proportional figures for aligned data. |
