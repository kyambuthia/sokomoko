## SOKOMOKO 
=========================
sokomoko is a small E-Commerce website written in go, HTML, CSS, JS and sqlite3 for the DB - no frameworks used.


## REQUIREMENTS 
========
Requires GO and a SQLITE3

clone the repository

`git clone github.com\kyambuthia\sokomoko.git`
